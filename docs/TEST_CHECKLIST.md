# M1.01 手机独立原型手动测试清单

- [ ] 离线打开 `index.html`，首屏可见、可输入文字。
- [ ] 新建一条测试记录，停止输入后可看到保存反馈。
- [ ] 关闭并重新打开同一浏览器与同一路径，记录仍存在（注意 file:// 兼容性）。
- [ ] 独白模式下无法触发 AI 眉批操作；没有任何网络请求。
- [ ] 切换共鸣后，选中文字可看到**静态**眉批占位，无真实模型请求。
- [ ] 添加小尺寸图片后可以导出备份；导入后内容能恢复。
- [ ] 两条记录可进入平行回声对照。
- [ ] 删除单篇后能从历史流移除，导出内容也不再包含它。
- [ ] 清除全部记录后界面为空；确认后再执行，确保没有误删。
- [ ] 使用浏览器开发者工具确认没有外部网络请求与私有令牌。

> 本清单是手测计划，并不表示上述测试全部已经通过。
